# Macroeconomic Research Project

This project explores how economic conditions change over time.

It uses public data from the Federal Reserve Economic Data (FRED) database to study indicators such as:

- Inflation.
- Employment.
- Unemployment.
- Interest rates.
- The relationship between short- and long-term rates.

The data is cleaned and combined so that the indicators can be compared over the same period. The project then creates charts and a short written report describing what the data shows.

Gemini is used as a research assistant to help organize observations and explain possible relationships in the data. Its output is treated as a starting point for analysis, not as unquestionable fact.

## Purpose

The purpose of this project is to practice:

- Working with real economic data.
- Understanding how macroeconomic indicators relate to one another.
- Turning data into charts and written explanations.
- Using AI carefully alongside source data.

## Important limitations

Economic data can be revised after it is published. The indicators do not all measure the economy in the same way or on the same schedule. Relationships between indicators do not automatically prove that one caused another.

This is an educational research project, not financial advice.
